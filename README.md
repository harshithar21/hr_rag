# RAG Assistant

## Overview
This project implements a local‑first, private document Retrieval‑Augmented Generation (RAG) assistant.

- **Backend**: FastAPI with health endpoint.
- **Vector store**: Qdrant (local persistence).
- **LLM**: Ollama chat model (reuse existing).
- **Frontend**: React + Vite + TypeScript.

Future work will add document ingestion, RAG logic, and voice interaction.
